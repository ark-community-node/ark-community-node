# Roadmap (12 months)

Every milestone ships in the open: code, results and docs in this repo.

| Months | Milestone | Done when |
|---|---|---|
| 0 | Gateway + chat page + benchmark harness; Mesh LLM verified as runtime | ✅ this repo |
| 1–2 | Reference images for an Intel N100 mini-PC and Raspberry Pi 5 | Measured words/sec, time-to-first-word and watts published with scripts |
| 3–4 | **Swahili benchmark v0.1** | ≥500 items reviewed by native speakers; results for 6+ small open models |
| 5–6 | **Lightning on the Node** | Mesh LLM `ln-payments-plugin` + LDK-backed self-custodial operator wallet; offline prepaid per-task metering; L402 API for agents. First Node live at a pilot site in Western Kenya |
| 7–8 | **Mesh LLM pooling + agent tools** | 2+ Nodes in a private, owner-restricted Mesh LLM mesh share compute; Goose/MCP tool pack (farming, school, health info, letters) |
| 9–10 | **Open Swahili fine-tune** | LoRA weights, data card, training scripts; benchmark v1.0 adds a second Kenyan language |
| 11–12 | **3+ Nodes in the field** | Non-engineer deployment guide; public report on usage, uptime, operator earnings and lessons |

## Metrics we will publish
Nodes live · unique local users · tasks served offline · Lightning settlements by operators ·
benchmark contributors · upstream contributions to the projects we build on.
